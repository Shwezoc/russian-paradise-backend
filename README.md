# RUSSIAN PARADISE — Backend starter v0.1

Первый серверный каркас на FastAPI + PostgreSQL. Он включает:
- проверку подписи Telegram Mini App `initData` по официальному алгоритму;
- выдачу короткоживущего JWT для последующих запросов;
- создание/обновление игрового профиля;
- хранение баланса, инвентаря и журнала операций;
- список аукциона, создание собственного лота и отмену лота.

## Важно
Это **стартовый каркас**, а не готовая публичная экономика. Покупка лотов, ставки, кейсы, казино, быстрые продажи, платежи и антифрод ещё не реализованы. Нельзя включать реальные покупки или запускать открытый аукцион до реализации этих операций и тестов. Токен бота и JWT-секрет нельзя публиковать в HTML или GitHub.

## Запуск локально
1. Нужен Python 3.11+ и PostgreSQL.
2. Создать БД `russian_paradise` и пользователя.
3. Скопировать `.env.example` в `.env`, заполнить `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`, `JWT_SECRET`.
4. Установить зависимости: `pip install -r requirements.txt`.
5. Запустить: `uvicorn app.main:app --reload`.
6. Проверить `http://127.0.0.1:8000/health` и документацию `http://127.0.0.1:8000/docs`.

## Telegram Mini App
Клиент должен отправить `Telegram.WebApp.initData` в `POST /auth/telegram` как JSON `{ "init_data": "..." }`. Сохранить полученный `access_token` в памяти приложения и передавать `Authorization: Bearer <token>` в защищённые запросы. Не использовать `initDataUnsafe` как доказательство личности.

## Frontend v0.4
Исходный статический интерфейс находится в `frontend/`. Запусти его без сборки из корня проекта:

```sh
python -m http.server 5000 --bind 0.0.0.0 --directory frontend
```

Затем открой `http://127.0.0.1:5000`. Локальная игра работает без Telegram; авторизация требует опубликованную HTTPS-страницу, открытую внутри Telegram Mini App, чтобы Telegram предоставил настоящий `initData`.

API разрешает CORS для `https://sweet-bavarois-1f4283.netlify.app` и, если задан `WEBAPP_URL`, для указанного там HTTPS/HTTP origin. Изменение действует только в этом проекте и не меняет опубликованный backend на Render.

- Добавить Alembic migrations вместо `create_all`.
- Включить HTTPS, CORS только для домена Mini App и rate limiting.
- Реализовать атомарные транзакции для всех операций с валютой и предметами.
- Добавить тесты конкурентных покупок/продаж и аудит ledger.
- Добавить обработку Telegram `query_id`/платежей только если появятся разрешённые платежи.
- Не хранить и не использовать реальные банковские деньги в игровой валюте; нет вывода средств.
